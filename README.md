# 515 Ganesan

React tribute website for social worker Alangudi Dr. 515 Ganesan.

## Pages

- Home (`/`)
- The Man (`/the-man`)
- Why 515 (`/the-515`)
- His Work (`/service`)
- Disaster Relief (`/disaster-relief`)
- Life Journey (`/journey`)
- Archive (`/archive`)
- Awards (`/awards`)
- His Voice (`/his-voice`)
- Family (`/family`)
- Legacy (`/legacy`)
- Contact (`/contact`)

Legacy redirects: `/biography` → `/the-man`, `/milestones` → `/journey`, `/achievements` → `/awards`, `/gallery` → `/archive`, `/recognition` → `/awards`, `/515` → `/the-515`.

## Setup

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
